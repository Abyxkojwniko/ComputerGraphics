### 🗂️ 卡片 2：C++ 进程内存五大分区

**问题：** 画出并描述 C++ 程序的内存布局（自高地址向低地址）。

**答案：**

1. **栈区 (Stack)**：存储局部变量和函数参数。**由高地址向低地址增长**。
    
2. **堆区 (Heap)**：通过 `new/malloc` 动态分配。**由低地址向高地址增长**。
    
3. **未初始化数据区 (BSS 段)**：存储未初始化的全局/静态变量，程序加载时自动清零。
    
4. **已初始化数据区 (Data 段)**：存储已初始化的全局/静态变量和常量。
    
5. **代码区 (Text 段)**：存储二进制机器指令。

### 🗂️ 卡片 3：静态局部变量 (Static Local) 的深度理解

**问题：** 解释静态局部变量的底层逻辑及示例代码。

**答案：**

- **核心逻辑**：静态局部变量在数据段分配空间。第一次执行定义语句时初始化，之后函数再次调用时不再初始化，直接复用旧值。
    
- **示例代码**：
    

C++

```
#include <iostream>
using namespace std;

void counter() {
    static int count = 0;  // 仅初始化一次，存储在静态存储区
    count++;
    cout << "当前计数值: " << count << endl;
}

int main() {
    counter(); // 输出 1
    counter(); // 输出 2 (记住了上次的结果)
    return 0;
}
```

### 🗂️ 卡片 4：全局变量 (Global) 与作用域屏蔽

**问题：** 全局变量如何跨文件使用？如果局部变量与它同名会发生什么？

**答案：**

- **跨文件访问**：使用 `extern` 关键字声明。
    
- **作用域屏蔽**：当局部变量与全局变量同名时，函数内部会优先使用局部变量。若要强制访问全局变量，需使用作用域解析符 `::`。
    
- **示例代码**：
    

C++

```
int var = 100; // 全局变量

int main() {
    int var = 10; // 局部变量屏蔽全局变量
    cout << "局部: " << var << endl;   // 输出 10
    cout << "全局: " << ::var << endl; // 输出 100
    return 0;
}
```

### 🗂️ 卡片 5：BSS 段与 Data 段的区别 (必考题)

**问题：** 为什么 C++ 要区分 BSS 段和 Data 段？

**答案：**

- **Data 段**：存放有初值的变量，必须在二进制文件里占用存储空间来记录这些初值。
    
- **BSS 段**：存放初值为 0 或未初始化的变量。它们在可执行文件中**不占实际空间**，仅记录所需大小。程序加载到内存时，内核会自动将这段空间清零。
    
- **目的**：优化磁盘空间占用，缩短程序加载时间。

### 🗂️ 卡片 6：如何选择合适的变量类型？

**问题：** 简述局部变量、静态局部变量、全局变量的最佳实践。

**答案：**

1. **优先局部变量**：最安全、内存随用随撤，防止命名污染。
    
2. **谨慎用静态局部**：当需要在函数多次调用间传递信息（如递归深度监控、初始化状态记录）时使用。
    
3. **少用全局变量**：仅用于全局配置。若需限制全局变量只在当前文件可见，需加 `static` 修饰。

#### 1. 修饰局部变量 (Local Static) —— “跨越时间的变量”
- **语法：** 在函数体内声明 `static int count = 0;`。
- **存储位置：** **全局/静态存储区** (.data / .bss)，**绝对不在栈上**。
- **生命周期：**
    - **生：** 程序**第一次执行到该声明语句时**初始化。
    - **死：** 程序运行结束 (main return) 时销毁。
    - _特点：_ 函数调用结束，值依然保留，下次调用继续用。
- **作用域：** 依然受限于**函数内部**（出了函数看不见）。
- **🔥 校招必考点 (Magic Static)：**
    - **C++11 之前：** 多线程下初始化 static 局部变量是不安全的（可能初始化多次）。
    - **C++11 之后：** 编译器保证初始化是**线程安全**的。这是实现 **Meyers' Singleton (单例模式)** 最标准、最优雅的写法。

#### 2. 修饰类成员 (Class Static) —— “全员共享”
- **数据成员 (`static int m_val`)：**
    - **归属：** 属于**类 (Class)**，不属于对象。所有对象共享这一份数据。
    - **Sizeof：** **不计入** `sizeof(对象)` 的大小。
    - **初始化：** 必须在**类外**进行定义和初始化（`int A::m_val = 0;`），除非是 `const static int` (整型特例)。
- **函数成员 (`static void func()`)：**
    - **特性：** **没有 `this` 指针**！
    - **限制：** 只能访问类的静态成员（变量/函数），**不能**直接访问非静态成员（因为没有 `this` 也就找不到对象的数据）。

#### 3. 修饰全局变量/函数 (Global Static) —— “私有化链接”
- **作用：** 改变**链接属性 (Linkage)**。
- **不加 static (普通全局)：** 默认是 **External Linkage (外部链接)**。其他文件可以通过 `extern` 访问它。容易导致重定义错误。
- **加了 static：** 变为 **Internal Linkage (内部链接)**。
    - 该变量/函数**只能在当前 .cpp 文件内**被看见。
    - 其他文件即使写了 `extern` 也找不到它。
    - _工程意义：_ 类似于 Java/C# 的 `private`（针对文件级别），避免全局命名冲突。

|**用法场景**|**存储位置**|**生命周期**|**作用域**|**链接属性**|**核心考点**|
|---|---|---|---|---|---|
|**局部 Static**|全局/静态区|程序全程|函数内|无|记忆上次的值；C++11线程安全单例|
|**类成员 Static**|全局/静态区|程序全程|类访问权限|外部(通常)|**无 this 指针**；不占 sizeof|
|**全局 Static**|全局/静态区|程序全程|当前文件|**内部 (Internal)**|**文件私有**，避免符号冲突|
- **别说“存在栈里”：** 只要有 `static`，它就在静态存储区，跟栈没关系。
- **别搞反链接：** Static 全局变量是**不能**被其他文件用的。
- **构造函数：** Static 成员变量**不能**在类的构造函数里初始化（因为它早于对象存在），必须在类外。
